# OpenCard 壳层重构计划

这份计划描述当前真实状态和后续施工顺序。工程规则见 `docs/工程规则.md` 与 `docs/UI_RULES.md`。

## 当前判断

`opencard-app/src/features/shell/OpenCardShell.vue` 当前约 1636 行，其中模板约 241 行、`script setup` 约 1382 行。已经移出渲染宿主、欢迎页、新建项目、模板导出、设置、关于/更新、工作台动作、工作台版本/差异行为、键盘快捷键、底部面板布局和全局覆盖层；根组件仍保留主布局模板、工作台 section 装配、窗口级接线、编辑器宿主接线，以及少量壳层级意图分派。工作台样式已归入现有全局壳层样式文件。

本轮重构的目标不是继续把函数搬到更多文件，而是让每个空间拥有自己的状态、投影和意图边界。

## 最终边界

```text
OpenCardShell
  应用布局、空间导航、流程返回、窗口、编辑器宿主、全局抽屉和关闭保护

WelcomeFeature
CreateProjectFeature
WorkbenchFeature
SettingsFeature
ExportTemplateFeature
AboutFeature
  各自拥有自己的状态、侧栏模型、内容模型和用户意图

通用组件
  只渲染模型并转发 typed intent
```

根组件不得直接保存模板、资源包、最近项目、设置分类、导出选择、版本树或更新反馈等功能状态，也不得组装跨领域 callback bag。

## 状态归属

| 功能 | 归属 |
|---|---|
| 最近项目、可用性、打开/移除/定位 | WelcomeFeature |
| 模板、资源包、选择、导入、附加、新建忙碌状态 | CreateProjectFeature |
| 项目树、项目管理、版本树、差异选择 | WorkbenchFeature |
| 设置分类、缓存、字体、主题意图 | SettingsFeature |
| 导出树、排除项、封面、校验、导出任务 | ExportTemplateFeature |
| 更新、发行说明、反馈入口 | AboutFeature |
| 空间切换、流程返回、窗口、侧栏布局 | OpenCardShell |
| 编辑器会话生命周期 | 现有编辑器宿主 composable；根组件只接线 |
| 问题 / 输出抽屉 | 唯一全局 drawer controller |

## 施工阶段

### 0. 计划与基线

- 更新本文件和交接文档，使其反映实际工作区。
- 保留已有未提交改动，不覆盖用户文件。
- 记录根组件行数、shell 定向测试和类型检查结果。
- 禁止再新增通用 callback router。

### 1. 先拆渲染宿主（已完成）

- 把根模板中的空间内容、流程页内容和对话框挂载移到薄的 `ShellRouteHost.vue` / 对应内容组件。
- 宿主只接收当前空间模型和少量壳层事件，不保存业务状态。
- 根组件只留下布局骨架、导航、窗口、编辑器宿主、全局抽屉和关闭保护。
- 已完成 `ShellOverlayHost.vue` 与 `ShellWorkspaceContent.vue`；行为不变。下一阶段继续把根组件降到 1500 行以下。

### 2. 下沉新建项目与模板导出（主体已完成）

- 将模板、资源包、选择、导入、附加和新建流程状态放入 `CreateProjectFeature`。
- 将导出选择、封面、排除项、校验和导出对话框状态放入 `ExportTemplateFeature`。
- 已完成新建项目、导出模板选择和项目导出任务状态的下沉；`create*Section()` 的大 options 装配仍待移入 feature 出口。
- 删除由迁移产生的重复状态和桥接函数。

### 3. 下沉工作台（动作边界已完成）

- 将项目文件树、项目管理、版本树、差异选择和工作台侧栏事件放入 `WorkbenchFeature`。
- 编辑器宿主仍由现有 composable 管理；根组件只负责会话生命周期接线。
- 工作台 intent 在工作台边界解码。
- 已删除 `shellWorkspaceIntent.ts`、`shellCommandIntent.ts`、`shellProjectEntryActions.ts`；工作台完整状态和 section 装配仍待继续收口。

### 4. 下沉欢迎页、设置和关于页（欢迎与设置已完成）

- 最近项目状态和动作归入 `WelcomeFeature`。
- 设置分类、主题、缓存、字体和设置意图归入 `SettingsFeature`。
- 更新、发行说明和反馈归入 `AboutFeature`。
- 欢迎页与设置状态已经有独立 feature；关于页的更新、发行说明和反馈仍与窗口级壳层状态同处根组件，待下一阶段拆出。

### 5. 删除中间层与收口

迁移完成后删除或合并：

- `shellCommandIntent.ts`
- `shellSettingsIntent.ts`
- `shellWorkspaceIntent.ts`
- `shellProjectEntryActions.ts`
- 仅生成侧栏描述符的重复 section 工厂
- 重复的 `shellSections.ts` 位置转发逻辑

保留纯位置模型、纯投影函数、布局 composable 和已有编辑器/窗口边界。

## 复杂度门槛

- 每个阶段根组件必须净减少行数；连续一次净增长就停下来重估边界。
- 不新增只有一个调用者的抽象、工厂或配置表。
- 不建立包含所有领域状态的总 context 或运行时 JSON 注册表。
- 最终根组件目标：约 800–1000 行；如果靠新增桥接文件才能达到，视为失败。

## 验证

- 每阶段运行 `npm run lint:ui`、`npx vue-tsc --noEmit` 和受影响的 shell 测试。
- 纯位置、投影和 intent 解码保持纯函数测试。
- 根组件不再出现领域 `actionKey === ...` 分派。
- 不存在跨项目、设置、编辑器、版本、更新的统一 callback bag。
- 真窗口检查三列布局、空间切换、流程返回、侧栏拖拽、底部抽屉和未保存保护。
- 用户可见行为变化才更新 `opencard-app/RELEASE_NOTES.md`；纯内部重构不写发布说明。
