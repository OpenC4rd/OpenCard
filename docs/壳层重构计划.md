# 软件壳层与空间页

本轮迁移已完成，约束见 `工程规则.md` 的“软件壳层与空间页”。本文件只说明当前入口和归属。

| 入口 | 职责 |
| --- | --- |
| `OpenCardShell.vue` | 固定框架、窗口交互、布局、当前页展示与软件生命周期接线 |
| `initializeAppPages()` / `useAppPages()` | 应用根初始化一次；其余调用只获取已有页面运行实例 |
| `SpacePage` | 内容组件、响应式侧栏与页头、问题模型、菜单贡献及对应回调 |
| `createWorkbenchPage()` | 编辑器会话、文件树、版本控制、导出、问题及工作台弹窗 |
| 其他 `createXxxPage()` | 各页自己的状态、表单、选择与业务操作 |
| `useApplicationActions()` | 跨页项目入口、外部打开、关闭协调；复用工作台未保存检查 |
| `useApplicationServices()` | 更新、反馈、发行说明及全局展示；关于页消费这些服务 |

事件路径为：页面提供 VM → 壳层呈现 → 组件报告操作 key 或树事件 → VM 提供者回调 → 页面更新响应式状态。壳层不翻译页面业务 key。

页面运行实例常驻，中间内容 DOM 按需挂载。新建项目与模板导出草稿不依赖组件引用；封面轮播等界面计时器随内容挂载和卸载。

下方面板外框与布局属于壳层；问题数据、展开与定位归当前页面，输出保持软件级共享。任务与即时消息不随空间切换清空。

清理删除中央操作解码、无行为透传和过时测试；保留保存重开、取消阻止破坏性操作、异步结果归属与不可信输入验证。验证不替代阅读生产调用链，界面是否正常需由实际运行观察确认。
