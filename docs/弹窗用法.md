# 标准弹窗用法

调用方声明内容和业务动作；`OcDialog` 负责模态范围、预设尺寸、焦点、滚动布局和外置侧栏。业务组件不覆盖弹窗容器的尺寸、padding 或定位。

```vue
<OcDialog
  v-model:open="open"
  title="编辑内容"
  size="xl"
  height-mode="fixed"
  height="workspace"
  sidebar-title="文字属性"
>
  <ContentEditor />

  <template #sidebar>
    <ContentProperties />
  </template>

  <template #footer-start>
    <ViewOptions />
  </template>

  <template #footer>
    <OcButton @click="cancel">取消</OcButton>
    <OcButton @click="save">保存</OcButton>
  </template>
</OcDialog>
```

`ContentEditor`、`ContentProperties` 和 `ViewOptions` 代表调用方自己的业务组件。`save` 完成校验和保存后才将 `open` 置为 `false`。弹窗不替业务提交草稿。

## 结构与行为

| 接口 | 含义 |
| --- | --- |
| `v-model:open` | 是否打开；Esc 或允许的背景点击发出关闭更新 |
| `size` | 主窗口宽度，使用 `sm/md/lg/xl` 预设 |
| `height-mode` / `height` | 内容自适应，或按 `sm/md/lg/workspace` 预设固定高度 |
| 默认 slot | 主窗口正文 |
| `footer-start` slot | 底部左侧辅助控件；共享容器负责与右侧操作分开 |
| `footer` slot | 底部右侧操作；共享容器负责按钮间距 |
| `sidebar` slot | 完整主窗口外部右侧的独立面板，与主窗口共用一个模态范围 |
| `sidebar` prop | 默认为 `true`；设为 `false` 隐藏侧栏和握柄，未提供 slot 时也不显示 |
| `sidebar-title` / `sidebar-tooltip` | 侧栏标题与握柄操作提示 |
| 可选 `v-model:sidebar-open` | 控制展开状态；未绑定时由弹窗自行管理 |

侧栏复用公共拖动控件，支持双击或 Enter 收起 / 展开、方向键调宽、从右侧边缘拉开，以及拖动中按 Esc 取消。空间充足时，侧栏展开和收起不改变主窗口宽度；窄屏时整体限制在视口内。

正文、侧栏分别滚动。隐藏侧栏保留本次打开期间的控件状态，隐藏字段不进入 Tab 顺序。普通弹窗不需要提供侧栏 slot，也不需要编写任何侧栏逻辑。

## Footer 间距

公共容器 `.oc-dialog__footer` 统一使用 `padding: var(--oc-dialog-footer-padding)`。共享主题将该值设为 `12px`，四边相同；已移除先前上下 `8px`、左右 `12px` 的两个独立值。

不要在业务层额外包装一个 footer 布局来补边距。左右内容分别放进 `footer-start`、`footer`，容器负责排列；业务组件只提供控件。
