# 添加教程

教程采用业务主动通知：业务决定开始与完成时机，store 管进度，根部的 `OcTutorial` 自动显示。只运行一组，退出后重头开始。

## 1. 标记界面目标

```vue
<aside data-oc-tutorial="workbench.files">...</aside>
```

同一目标 key 在当前可见界面中必须唯一。共享侧栏列表可通过 `ShellList.tutorialKey` 指定标识。

## 2. 添加定义和文案

在 `opencard-app/src/features/tutorials/tutorials.ts` 的 record 中添加一项；标题与说明是 i18n key，需同时补齐中英文。

```ts
openFile: {
  title: 'tutorial.openFile.title',
  steps: [
    {
      id: 'overview',
      manual: true, // 说明步骤显示“下一步”；省略则等待业务通知
      targets: [
        { key: 'workbench.files', title: 'tutorial.openFile.filesTitle', desc: 'tutorial.openFile.filesDesc' },
      ],
    },
    {
      id: 'open',
      targets: [
        { key: 'workbench.files', title: 'tutorial.openFile.openTitle', desc: 'tutorial.openFile.openDesc' },
      ],
    },
  ],
},
```

`targets` 可以包含多个区域，组件同时高亮，并用一张说明卡展示。操作型教程只允许点击当前高亮区域、这些区域打开的浮层和教程按钮；其余页面区域由遮罩接收鼠标命中，不响应点击、悬停、提示和光标变化。目标暂不可见时可重新定位或结束。

单个目标可设 `interactive: false` 保持高亮但不允许交互（例如顶部介绍中的菜单）。步骤可通过 `blockInteraction` 覆盖整组的交互限制；例如界面介绍的侧栏开关步骤和最后的新建项目步骤设置为 `false`，允许操作高亮目标。进入新建项目页后，该页面完成界面介绍的最后一步，再按首次进入条件启动创建项目教程。纯演示教程在定义上设置 `blockInteraction: true`，遮罩拦截背景点击，并与弹窗共用模态层管理背景 `inert`、焦点和快捷键，仅说明卡可操作。无定位目标的欢迎步骤可使用 `targets: []` 和 `message: { title, desc }`；`nextLabel`、`exitLabel` 可指定按钮文案。首次欢迎界面介绍使用 `overview`，创建项目的操作教程仍使用 `welcome`。

侧栏、底部面板按当前目标 `shell.sidebar`、`shell.bottom-panel` 临时展开，结束该步骤后恢复，不依赖教程名称。操作型教程可指向弹窗内的目标；说明与遮罩跟随所属弹窗，更上层弹窗关闭后恢复显示。创建项目教程由 `createCreateProjectPage` 在首次进入新建项目页时触发，从模板选择开始；该页面也负责跳步和完成通知，表单本身只返回创建结果。欢迎页没有教程启动按钮。

## 3. 业务主动通知

```ts
const tutorial = useTutorialStore()

// 放在按钮回调、页面进入逻辑等合适的位置，业务自行判断是否需要开始。
tutorial.start('openFile')

// 异步操作先捕获本次教程运行编号，避免退出重开后的旧结果推进新教程。
const run = tutorial.session.value?.run
await openFile(path)
if (run !== undefined) tutorial.completeStep('openFile', 'open', run)

// 用户退出不会回滚业务操作。
tutorial.exit()
```

看过的教程保存在 `settings.json` 的 `tutorials.seen` 数组中，成功启动时自动登记。设置 → 常规 → 教程以标签显示这些记录；移除标签并保存后，再次进入对应页面即可重新触发。清理缓存不会清除记录，重置设置会清除。引擎允许主动重看，是否自动启动仍由各业务入口自行判断。
