# OpenCard 软件错误码

本文档是 OpenCard 运行时软件错误码的查询手册。工作区“输出”栏只显示各模块主动提供给用户的信息和已分类的失败，不镜像开发者控制台；每条记录统一显示时间、级别和内容，带错误码的记录会另起一行给出该次失败的具体明细，完整诊断信息可通过点击条目复制，解决方案仅在本文档维护。

## 编号规则

当前约定使用 `OC-E####` 并按领域分段。项目仍处于早期开发阶段，错误码尚不是对外兼容 API，可以根据实际架构重编号、合并、拆分或修改含义。

| 范围 | 领域 |
| --- | --- |
| `OC-E1xxx` | 应用与通用能力 |
| `OC-E2xxx` | 工作区与文件系统 |
| `OC-E3xxx` | 项目与项目资源 |
| `OC-E4xxx` | 编辑器与文档 |
| `OC-E5xxx` | 渲染与导出 |
| `OC-E6xxx` | 更新与安装 |

未携带错误码的错误条目直接显示原始消息，不进入错误码目录。排查带错误码的问题时应复制完整错误块，并附上操作步骤、相关文件和应用版本。

## 错误码目录

| 错误码 | 含义 | 解决方案 |
| --- | --- | --- |
| `OC-E1002` | 无法写入系统剪贴板 | 确认系统允许 OpenCard 访问剪贴板，关闭占用剪贴板的安全软件后重试。 |
| `OC-E2001` | 无法读取目录内容 | 确认目录仍然存在且当前用户具有读取权限，然后刷新项目文件树。 |
| `OC-E2002` | 无法处理外部文件打开请求 | 确认文件路径有效且文件类型受支持；重新从文件管理器或 OpenCard 的打开命令进入。 |
| `OC-E2003` | 无法打开文件 | 检查文件是否存在、是否被其他程序独占以及当前用户是否具有读取权限。 |
| `OC-E2004` | 无法在文件管理器中定位文件 | 确认文件路径仍然有效，并检查系统文件管理器是否可以正常启动。 |
| `OC-E2005` | 无法刷新项目目录索引 | 检查项目目录访问权限，关闭后重新打开项目；若持续出现，请检查磁盘状态。 |
| `OC-E2006` | 无法启动项目文件监听 | 重新打开项目；确认项目所在磁盘支持文件监听，且系统监听句柄未耗尽。 |
| `OC-E2007` | 无法重命名文件或目录 | 确认目标名称合法、目标路径不存在同名项，并检查文件是否被占用或缺少写入权限。 |
| `OC-E2008` | 无法移动文件或目录 | 确认目标目录可写、没有同名项，并检查源文件是否被其他程序占用。 |
| `OC-E2009` | 无法把外部文件复制到项目 | 确认外部文件仍存在、目标文件夹可写且磁盘空间充足，然后重新拖入。 |
| `OC-E3001` | 无法激活项目 | 确认项目目录完整且可访问；修复项目配置文件后重新打开项目。 |
| `OC-E3002` | 无法加载项目配置 | 检查项目配置文件的语法与编码；可从备份恢复有效配置后重试。 |
| `OC-E3003` | 无法加载项目字典 | 检查字典文件是否存在、内容是否为有效格式，并确认项目配置中的路径正确。 |
| `OC-E3004` | 无法将字体注册到项目 | 确认字体文件有效且项目配置可写，然后重新执行“注册到项目”。 |
| `OC-E3005` | 无法加载项目字体 | 检查字体文件路径、格式和访问权限；移除损坏的字体注册或替换字体文件。 |
| `OC-E3006` | 项目配置草稿无效 | 撤销最近的项目配置修改，检查必填字段和数据格式后再次保存。 |
| `OC-E3007` | 无法导入项目字体 | 确认所选文件是受支持且未损坏的字体文件，并检查项目目录写入权限。 |
| `OC-E3008` | 无法打开项目字典 | 确认字典路径有效；若文件不存在，先在项目配置中重新创建或选择字典。 |
| `OC-E3009` | 无法加载项目字体注册表 | 检查 fonts.json 的语法、字体 Key 与项目相对路径，然后重新打开项目。 |
| `OC-E3010` | 无法加载项目图标 | 检查 icons.json 的语法、图标 Key 与项目相对路径，然后重新打开项目。 |
| `OC-E3011` | 无法导入项目图标 | 确认所选图标文件受支持且未损坏，并检查项目目录写入权限。 |
| `OC-E3012` | 注册表草稿无效 | 在源码中修复注册表 JSON，确认内容有效后再次保存。 |
| `OC-E3013` | 无法导入图标包 | 确认 .ociconpack 文件包含有效的 JSON 与所声明的图标文件，并检查项目目录写入权限。 |
| `OC-E3014` | 无法导出图标包 | 确认项目图标文件可读取，并检查目标路径和磁盘写入权限。 |
| `OC-E3016` | 无法读取项目里的资源包 | 检查 .opencard/packages 下的 .ocpack 文件是否完整、项目目录是否可读，然后重新打开项目。 |
| `OC-E3017` | 无法解开资源包 | 确认归档完整、磁盘剩余空间足够且缓存目录可写；删掉 ~/.opencard/cache/snapshots 可以让程序重新解一次。 |
| `OC-E4001` | 无法在预览会话中打开文件 | 确认文件仍然存在且可读取，然后重新点击文件；必要时固定或关闭旧预览会话。 |
| `OC-E4002` | 无法同步编辑器保存结果 | 保留当前编辑内容，检查目标文件写入权限后再次保存；不要在确认写入前关闭会话。 |
| `OC-E4003` | 无法读取卡牌文档 | 检查 .ocdocument 文件是否为有效 JSON 和受支持的数据结构；从备份恢复损坏内容。 |
| `OC-E4004` | 无法保存卡牌文档 | 检查文档内容、目标路径和磁盘写入权限，然后再次保存。 |
| `OC-E4005` | 无法加载文件路径补全 | 刷新项目目录索引并确认相关目录可读取；仍失败时可直接输入有效相对路径。 |
| `OC-E5001` | 没有可导出的活动文件 | 先打开并激活一个 .ocdocument 文件，再执行导出。 |
| `OC-E5002` | 活动文件不支持卡牌导出 | 切换到 .ocdocument 文件后重新执行导出。 |
| `OC-E5003` | 活动卡牌文档内容为空 | 先为当前 .ocdocument 文档添加有效内容并保存，再执行导出。 |
| `OC-E5004` | 无法解析待导出的卡牌文档 | 修复文档中的语法或结构错误，确认编辑器不再报告问题后重新导出。 |
| `OC-E5005` | 无法导出卡牌图片 | 检查导出目录写入权限、磁盘空间和卡牌资源是否可加载，然后重试。 |
| `OC-E5006` | 无法批量导出卡牌图片 | 检查所有实例数据与资源是否有效，并确认导出目录可写且磁盘空间充足。 |
| `OC-E5007` | 无法完成卡牌渲染 | 检查图片、字体等资源能否加载，降低导出尺寸后重试；持续失败时提交错误详情。 |
| `OC-E6001` | 无法完成应用更新操作 | 确认网络与磁盘空间正常，退出可能占用 OpenCard 文件的进程后重新检查更新。 |

## 维护规则

- 早期开发阶段不维护错误码的历史兼容；不合理的编号和分类应直接调整，无需保留废弃编号。
- 任何新增、重编号、合并、拆分或含义调整，都必须在同一次变更中同步运行时目录、全部调用点、本文档和测试。
- 同一版本和同一次构建中的错误码、含义与解决方案必须保持唯一且一致。
- 同一故障含义复用同一编号；不同解决路径或用户动作应使用不同编号。
- 错误码描述面向用户说明“发生了什么”，不得暴露实现类名或把解决方案写进含义。
- 原始异常、路径和上下文属于诊断详情，不作为错误码含义的一部分。
