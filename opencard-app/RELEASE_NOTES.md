## 新增

- 新增项目结构适配：打开旧项目时可一键适配，适配前自动保存 Git 快照
- 新增版本图表操作：撤销提交、回退，以及单独恢复某个文件
- 新增位图图标裁切，可把一张图按格子或行列切成多个图标
- 新增应用内文件选取器，项目封面可直接从电脑导入图片
- 新增 macOS 窗口材质
- 新增官方答复的 Markdown 显示
- 新增默认跟随鼠标的悬浮提示模式
- 新增 Markdown 与文本文件的创建入口
- 新增语言文件的完整键名基底
- 新增小贴士，可以在设置中控制开关和频率
- 新增引导系统，初步新增两套引导：“界面介绍”和“创建第一个项目”
- 新增教程：“在项目中工作”
- 新增教程：“初始化版本库”和“使用版本管理器”
- 新增引导可交互区域的鼠标提示
- 新增图片块透明度遮罩
- 新增自定义块集合管理
- 新增文件树多选操作
- 新增卡片编辑器中字体、图标、自定义块选择器直达对应管理文件
- 新增面板尺寸的键盘调节
- 新增富文本属性的清除格式操作
- 新增卡片画布与富文本编辑器的比例尺
- 新增过渡速度设置
- 新增忽略项编辑器，源码与规则列表联动，在协作页点击即可打开
- 新增预览版更新渠道
- 新增自定义属性的定义编辑
- 新增富文本、图像来源、字体和自定义块来源属性类型
- 新增画布点阵间距设置
- 新增颜色字段的半透明棋盘格预览
- 新增颜色透明度滑条的棋盘格底
- 新增选中块的旋转手柄与刻度
- 新增按住 Alt 对称缩放选区
- 内缩/外扩快捷键改为每次 1 mm
- 新增导出文档搜索的方向键选择
- 新增操作条空间不足时自动收进“更多”
- 新增卡片预览的纯白、纯黑和棋盘格背景

## 变更

- 未打开项目时，协作入口改为隐藏，打开后平滑出现
- 图标属性显示类型、文件和尺寸，多选时可批量修改
- 图标页的格子大小与字体页的预览字号改为小、中、大三档
- 图标集改为每套一个文件夹，复制文件夹即可分享；集的 Key 不再能在设置里修改
- 变更协作页的“提交版本”为“创建存档点”
- 优化卡片编辑器在设计视图与数据表之间切换的过渡动画
- 移除卡片编辑器的边缘裁切开关
- 实例删除属性后改用默认值，不再跟随蓝图
- 形状、二维码、图片和容器的内容与样式属性可以删除
- 新建块只带常用属性，其余按需添加
- 新增导出空间，可在侧栏管理多份导出配置
- 新增导出预览，调整配置时实时查看版面
- 导出预览支持 PDF 单页和双页查看
- 导出文档支持文件夹和通配符选择
- 新增拼版 PDF 导出，可设置纸张、版面和裁切标记
- 拼版 PDF 按卡牌尺寸自动分页，同尺寸连续排列
- 拼版 PDF 新增铺满，卡片均匀分布到整页
- 新增导出文件名和文件夹的变量，如日期和项目名称
- 图片导出可配置文件名，支持文档和卡片变量
- 新增导出完成后打开文件夹的开关
- 新增导出的清晰度和版面预设，细节收进高级配置
- 导出配置打开时只读，编辑后点保存才写入，可取消
- 新增导出页底部的开始导出按钮
- 新增 PDF 页面信息，可在边距区域放富文本、页码和项目图标，并设置对齐
- 新增导出水印，支持富文本，可设置角度、密度和透明度
- 新增 JPEG 图片导出
- 预览版的 Linux 安装包不再提供 rpm 格式
- 旋转、缩放与移动时的实时读数固定一位小数并使用等宽数字字体，数字不再跳动
- 彻底取消像素单位支持
- 移除旧版富文本 HTML 渲染支持
- 卡牌尺寸与排版基准单位改为毫米
- 导出规格改为印刷 DPI
- 统一卡片富文本标记语法（AtTag）
- 提升卡片画布交互性能与吸附精度
- 提升卡片画布平移、缩放与素材加载时的重绘性能
- 卡片画布改为按可见区域绘制，缩放平移全程清晰并减少内存占用
- 文字投影现包含下划线、删除线和行内图标图片
