# 发行说明草稿

## 新增

- 容器块可以导出成 `.ocblock` 自定义块：在别的文档里复用它，公开出来的字段直接在属性面板里改，也能把自定义块再套进自定义块。这类文件在文件树和编辑器里有自己的积木图标，和普通文本一眼分得开。
- 项目管理树新增“自定义块”一栏：登记项目里的 `.ocblock` 源、显示名称和引用 Key，新增条目会自己避开重复的 Key；挑源时会补全项目和资源包里的可用路径。
- 制作资源包时能挑要公开的自定义块；包详情页会列出这个包公开了哪些块。
- 资源包的身份由包自己在清单里写明，就是「作者/包名@版本」：把 `.ocpack` 放进项目的 `.opencard/packages/` 就算装好了，项目里有哪些包就是文件夹里有哪几个归档，不再需要另一份包清单。文件叫什么名字、放在哪里都不改变它是谁，别人给你的项目、或者你自己改过名的包，打开之后还是同一个包。
- 卡片引用包内资源时，版本写不写由你定：写了就把长相钉死在那一版，不写就用装着的里面最新的那一版。
- 侧栏 `.opencard/packages` 那一行现在能点开“包”页面：一份归档一张卡，标题是文件名，下面一行小字是包自己声明的坐标，卡片上画着包的封面（还没解开的包媒体区留空）。说不清自己是谁的归档不会被藏起来，而是单独列出并说明原因。卡片上有“在文件管理器里显示”和“移除包”，移除会先问一次，确认后把归档移到回收站，想反悔从回收站拿回来放回去就行。点卡片直接看包详情：封面、内容特征码、清单，包没解开也看得见。
- 打开的包不再解到项目里，而是解到软件存储的缓存、按内容特征码命名，所有项目共用：同一个包在多少个项目里用到都只解一次，缓存也可以随手删掉，下次用到会重新解一遍（缓存有大小上限，超出上限的部分留到下次启动再清）。
- 打开项目时，还没解开的包在后台排队解压，不挡住打开项目；某个包在这台机器上第一次被用到时会空一拍，随后自己补齐。
- 加包还是老样子：把一个 `.ocpack` 拖进已打开的项目，或者在侧栏 `.opencard/packages` 那一行点“添加包”选一个文件，它就复制进项目；在“新建项目”页勾选的包也会一起复制进去。归档按原样复制、名字不变，撞名就排下一个编号（`名字 (2).ocpack`），不覆盖已有的那一份。
- 包这一行的操作和文件树里的文件完全一样：重命名、移到回收站、在文件管理器里显示、复制相对路径与绝对路径；把 `.ocpack` 从外面拖进结构树也能装包。
- 图片块的来源除了填写文件路径，还能直接挑项目图标或包内图标：输入 `icon:` 会列出当前项目的图标集，以及带图标的包；选中某个包之后候选里会继续出现 `icon:`，一路选下去就写入该包的图标引用，直接输入 `作者/包名@版本#` 也能接着补全。
- 富文本的图标菜单现在按来源分组：当前项目和每个包各列一组；插进去的图标会记住自己来自哪个包，只读预览和卡片渲染都会照常显示。
- 外观设置的主题预设里多了“石墨”：底色和文字颜色沿用所属主题，只把主题色换成纯黑或纯白，深色与浅色两套里都能直接选。
- 外观设置多了“窗口云母背景”：打开后窗口底层交给 Windows 11 的云母材质，标题栏与面板之间的空隙会透出桌面壁纸的质感，并跟着深色／浅色主题取明暗；系统不支持时会说明，界面保持原来的不透明底色。
- 添加项目字体时除了从文件导入，还能导入电脑上已经装好的系统字体：切到“从系统字体导入”，按名字搜索或者在树里展开字系核对识别到的字面，勾一个或多个之后确认，每个字系的字重与斜体会各自整理成一套项目字体复制进项目。勾过的字系可以用“只看已选中”过滤，列表里的字系名会用该字系自己的字体显示。
- 设置里新增“协作”分类：作者身份搬到了这里，另外可以填提交者名称与邮箱，并决定初始化仓库后要不要自动创建首次提交。提交者名称留空就用作者身份，邮箱留空就按名称生成一个地址，填一次之后每个项目都用这套身份。
- “更改”列表里每条改动后面都有一个勾选框（默认全勾）：点“提交版本”只提交勾上的，没勾的原样留在工作区，按钮上会显示这次会带上几条。
- “更改”列表里每条改动都能右键放弃更改：提交过的内容回到最近一次提交，新增的文件移到回收站，动手前会问一次。
- 每条改动也能右键忽略：忽略此文件、忽略此文件夹（子菜单列出从它自身到项目根的每一级）、忽略所有这类文件（例如所有 `.ocpack`）。规则写进项目的 `.gitignore`，被忽略的未跟踪内容随即从列表里消失；已经提交过的文件不受影响。
- 设置“通用”里多了“缓存”卡片：解开的包、下载过的图片、撤销暂存各占多少一眼可见，解开的包和下载的图片各自能调上限（默认 2 GB 与 1 GB），需要时点“清理缓存”整块清掉。清理不会丢东西——包的本体留在项目里，下次打开重新解开；下载过的图片下次用到重新下载。超出上限的部分留到下次启动再收，一边用不会一边清；项目打开着的时候不提供清理，免得删掉正在用的东西。
- 图标集现在能直接补图标：在图标集那一行点“添加图标”，挑几个文件或者一整个文件夹，新图标会和这个图标集原有的图标放在同一个文件夹里，不必为了多几个图标重建整个图标集；给图标集改名或改 Key 仍然只在“图标集设置”里做。
- “内置的包”里多了图标包 game-icons（作者 game-icons.net，版本 1.0.0）：23 个图标集、共 1575 个游戏图标，在“新建项目”页勾上就随项目一起装好，之后按包内图标集挑选。
- 左侧空间栏新增“集市”和“测试”：集市将来用于浏览、下载资源包，测试将来用于联机游玩导出的桌游；现在这两个页面先显示敬请期待。
- 文件菜单新增“打开文件”“另存为”和“全部保存”，不打开项目也能直接编辑外部文件；“关闭项目并返回欢迎页”改名成“关闭项目文件夹”。
- 界面语言可以自己扩：把一份语言文件放进软件存储根的 `locales` 文件夹，语言列表里就会多出这一项，显示的名字就是文件名。文件里先写明它以简体中文还是英语为基底，然后只写你想改的文案，没写的条目继续沿用基底语言的说法，所以不必一次翻完。放好之后在“设置 → 常规 → 界面”点“重新读取语言文件”即可生效，卡片上的“打开语言文件夹”会直接打开这个文件夹。选中的语言文件之后被删掉时，界面会回到默认语言并在标题栏提示一句，设置里的选择仍然保留，把文件放回去再读一次就还是它。

## 改进

- 文件夹图标统一使用同一种颜色，展开与收起通过图标形状区分。
- 打开编辑器或者切换工作区时，标题还没准备好的编辑器先显示骨架占位，不再短暂留出空白；左侧“打开的编辑器”列表也保持行高稳定，标题准备好后自动替换。
- 文件树节点有多个操作时统一收进操作菜单：第一次点击打开菜单，随后滑动即可切换操作，避免误触相邻按钮。
- 带子菜单的操作统一改成点击后展开，鼠标经过不会意外弹出菜单；已打开的子菜单仍按原方式继续操作。打开时图标会旋转，关闭后恢复，当前状态更容易辨认。
- 结构树展开容器时，父节点图标以 45° 动画旋转，展开状态更容易辨认。
- 设置等属性页面每行内容保持统一的上下留白，多行说明不会紧贴分组标题或分隔线。
- 属性面板里的块不再显示“ID”和“类型”这两行只读字段：它们改不了，也不该被当成设置项。块的“高级”分组里只剩“自定义 CSS”；自定义块没有这一项，因此不再出现“高级”分组。
- 没打开项目时，工作台会提示可以直接打开文件或项目；侧栏保留已打开的编辑器，并隐藏依赖项目目录的项目管理、文件树和版本控制，不再显示上一个项目的遗留内容。
- 界面新增“空间”栏：首页、工作台和设置从同一列直接切换，空间栏与工作区标题头使用同一背景，当前空间图标跟随主题强调色；工作区侧栏收起后会与内容框架贴合，边界圆角自动变为直角。标题栏的欢迎页／工作台切换按钮、设置侧栏的“返回”以及首页和工作台侧栏的“设置”按钮一并移除；工作台里的“协作”分组继续保留版本与更改入口。
- 工作区内容与底部的“问题／输出”面板现在是两个同级面板，外侧圆角保持一致；展开时两块区域之间有与侧栏一致的可拖拽分隔条，收起时两块区域会贴合。
- 设置页改为平铺分组：每组不再有卡片底色和描边，只保留标题栏与行之间的分隔线，整页直接落在窗口底色上；开启“窗口云母背景”时，设置页会与标题栏一样透出系统材质。
- 界面基准字号现在的调节范围是 13–19 像素（原来 10–16），默认 13：高分屏或者觉得字小的可以整个界面一起调大；以前手动调到 13 以下的设置会被抬到 13。
- 设置页每一行的输入区改成统一宽度：颜色、文字、数字、下拉、选项组与滑块都占同一宽度，选项组不再随文字长短伸缩，滑块也不再独占整列。
- 表单里的选项组（设置页的主题，以及属性面板里的同类字段）改用滑动描边样式：与侧栏的工作区切换一致，选中框会滑到新选项上，不再只靠按钮底色区分。
- 滑块圆点改成单色实心圆，刻度落在该在的位置，手柄不再随悬停或拖动改变大小——圆点边缘不再发虚，刻度也不再一根粗一根细。
- 滑块当前值显示在拇指上方：悬停、拖动或键盘聚焦时出现，鼠标移开就把整条滑轨的宽度让回来，带单位（`%`、`°`、`px` 等）时单位跟在数值后面。以前只有带单位的滑块才显示数值，现在每个滑块都看得到当前值。
- 开关在切换时小圆先朝行进方向拉长一点、再滑过去收成正圆；系统要求减少动态效果时不播放这段动画。
- 项目设置的封面改成整幅图片预览：点封面就能从项目文件夹里挑图片，图片路径与移除操作收在封面底部的毛玻璃信息条里（悬停时出现移除），不用再手填图片路径；包清单页面的封面也统一改用同一套呈现。
- 包详情页里“字体”与“图标集”每行的 Key 改用和“包信息”里坐标、内容特征码相同的写法（等宽、正文颜色），同一页里不再一处发灰一处发亮。
- 包详情页的“包信息”点一下那一行就把值复制走（坐标、显示名称、内容特征码都行），卡片头部原来的两个复制按钮随之撤掉。
- 项目图标页重新按图标本身排布：左边是图标集列表，中间是当前图标集的图标网格——每张卡片正面画的就是这个图标，悬停时出现复制、移动与移除；右边是选中图标的预览与属性，属性不再占用一块可收起、可拖高的浮动面板。预览可以用滚轮缩放、拖动平移，双击或点工具栏上的“适应窗口”回到原来的大小；换一个图标或换一个图标集，缩放都会回到默认大小。选中多个图标时右栏会说明已选了几个，卡片上的操作会同时作用于它们。
- 设置页按主题重新分组：每个分类下的设置分成一张张卡片（外观下是“深色主题”“浅色主题”“界面”，工作区下是“保存与历史”“文件树”“画布辅助”），卡片自带标题，作用于整组的操作放在卡片上。一条设置只承载一个值，深色与浅色主题不再层层嵌套。
- 主题预设的复制与读取改为一对卡片操作：在一套主题的卡片上“复制这套主题预设”，再在另一套主题或另一台设备上“从剪贴板读取主题预设”，不再需要先弹出窗口粘贴 JSON；删除导入的预设、重新生成作者 ID、重置本项目的界面状态也一并移到了对应卡片上。
- 主题卡片新增“主题名称”一行：给当前这套配色起个名字就会存成一条自定义预设，改名字就是给它改名，配色、字体与次级颜色相位角一起记住；不必再靠复制成 JSON 再读回来才能留下自己的配色。
- 配色相同、名字不同的两条主题预设不再互相顶替，预设列表里也不再用“已导入”当后缀。导入一套与已有预设完全相同的主题时不再多出一条重复的预设，只会把已有的那条选上；名字撞车但配色不同的导入会自动加序号，不再顶掉前一条。
- 欢迎页背景封面墙每次打开应用都换一个排布与取景：同一张封面在不同格子里露出的部位不再一样，整面墙也不再次次是同一张图案。
- 欢迎页左下角控制背景效果的开关换成了一个图标按钮（全景图标）：按一下收起封面墙与引力背景，再按一下放回来；背景开着时按钮保持按下态，鼠标停上去能看到它的名字。
- 卡牌编辑器里按住 Shift 拖动选择框的缩放点就是等比缩放：宽高按原比例一起变，松手前就能从选择框上看出结果。跟手的是比较长的那条边（拖边时就是那条边自己），所以整段拖拽只有一个方向在跟指针，不会拖到一半换方向、来回抖。等比缩放时对齐吸附照常生效，而且两条边都能吸：哪条边离对齐线更近就吸哪条（包括不跟手的那条），吸上之后比例仍然保持不变，引导线也只画在真的吸住的那条边上。
- 下拉选择与自动补全的候选行改用统一条目样式：当前高亮项与已选项现在能区分开（已选项用与树、列表一致的选中底色）；自动补全的说明文字从候选右侧的第二列改为标题下方的一行，长短不一时不再互相挤压。
- 反馈历史列表里选中一条记录时，底色改为与属性面板等其它列表一致的选中色，不再是另一种灰底。
- 项目字体与字体组合的添加入口从编辑器标题栏移到左侧列表：鼠标移到“项目字体”或“字体组合”这一行，或在该行右键，就会出现对应的添加入口（“添加字体”“创建字体组合”），标题栏不再常驻两个加号。
- 添加字体对话框顶部改成“从文件导入／从系统字体导入”两种来源的切换，各自显示对应的内容；从文件导入保持原来的做法（选择字体文件后自动识别名称、字重和样式），并且对话框不再一打开就弹出文件选择框。
- 字体管理器左侧列表里，项目字体和字体组合的名字现在用它们自己的字体显示：字体条目用它自己的字面绘制，组合按成员的回退顺序绘制，不必再靠右侧预览区确认某个名字对应的是哪套字体。
- 设置页把原来那张“更新与导出”拆成“更新”和“导出”两张卡片，各自只放自己的设置：更新一侧的开关改成“展示版本说明”（打开即更新后自动弹出版本说明，默认打开），导出一侧是“导出后自动打开”。
- “更改”列表里每条只显示文件名，不再显示整条相对路径；同一层里出现同名文件时，只给重名的那几条补上能区分的目录，其余仍只有文件名。位于 `.opencard`、`.git` 这类点开头目录中的文件各自收进一个同名子节点（默认展开，可以收起），普通文件直接列在根上；版本图里每次提交的文件清单也按同样规则显示。
- 项目配置新增“项目作者”字段；制作资源包时的作者默认填入它，不再和设置里的作者 ID 联动——原先制作页会把你填的作者写回设置，现在两边各管各的，包作者只在项目内记住。
- 制作大包明显更快、占用更低：制作时进度条会随文件推进而不是一直停在起点，已经压过的图片与字体不会重复压一遍。
- 包摘要会列出包里各式内容的数量（字体、字体组合、图标、图片），并且给包身份留出四个输入框：作者、包名、版本，以及给人看的显示名（留空就用包名）。不再单独显示一行只读的“包 Key”。
- 打包资源包时把用到的资源复制进包里：来自别的包的字体与图标会以它们在来源包里的相对路径放进新包，新包里不再有任何对别的包的引用，也不需要一份依赖清单。项目自己的资源照旧按它们在项目里的位置进包。
- 设置页每条设置现在可以带一行说明文字：标题只留短名字（例如“即时信息”“自动保存”“历史记录上限”“结构树选中”“滚动定位”“定位辅助线”“宽高标签”“自动吸附”“首次提交”“导出后自动打开”），原本塞在标题里的解释挪到标题下方的小字里显示。
- 启动封面、关于页与 `.ocpack` 文件类型图标里的 OpenCard 标志改用矢量图形：放大到任意尺寸、在高分辨率屏幕上边缘都不再发虚，重新生成文件类型图标时也不再依赖外部的标志位图。
- 初始化仓库不再弹出询问身份的对话框：直接使用设置里“协作”分类的提交者身份，并按其中的选项决定要不要顺手创建首次提交；名称与邮箱都能从作者身份兜底，只有 Git 不接受这套身份时才会把你带到对应的设置项。
- “新建项目”页的模板与包都改成两个分组：模板下是“内置模板”和“我的模板”，包下是“内置的包”和“我的包”（内置包来自随安装包一起发布的包）；两组默认展开，可以随时收起。
- 删除用户模板不用再先选中它、再回到右侧详情里点按钮：把鼠标移到“我的模板”里的模板那一行，直接点行尾的删除图标即可，确认后移除。内置模板不提供这个入口。
- 移除包、删除模板时的确认改成了应用内对话框，和其余弹窗同一套外观，不再弹出操作系统的消息框。
- “预装的包”列表支持多选，列表头部在“导入包”旁边新增“使用选中的包”和“禁用选中的包”，可以一次把选中的包全部预装或全部取消；树里的每次单项切换仍然保留。包相关的措辞统一为“包”。
- “打开的编辑器”列表与页面顶端的标题、图标现在始终是同一份：显示编辑器自己给出的名称与图标，不再出现列表一个名字、顶端另一个名字；受管文件也跟着这样显示（项目配置显示“配置”，包显示文件自己的名字与它声明的坐标）。双击文件不会再把这个名称变回文件名，编辑器给出名称之前两处保持空白。
- “打开的编辑器”列表里的字体文件图标与文件树保持一致：没有登记到项目字体的字体文件按未登记呈现，不再出现同一文件在文件树里变暗、在列表里却是彩色。
- 卡牌编辑器里新建的块一出场就带上自己的尺寸和该有的样式：每个新块都有宽高，文本块与 Markdown 文本块还带上字号、字重、字体颜色、对齐方式与行高，不必先去属性面板逐项“添加”。以前文本块没有字号，卡片上的文字会跟着软件界面的字号一起变；现在卡片自己说了算。旋转、不透明度、描边、圆角、自定义 CSS 这些仍然保持未添加，需要时再从属性面板加上。
- 字体页的“项目字体”与“字体组合”为空时各自显示一行不可选中的说明（“项目里还没有字体。”“还没有字体组合。”），和“预装的包”里空分组的样子一致；树上的数量徽标也不再把这些占位行算进去，空分组不会再顶着一个“1”。
- 工作区标题栏与下方内容之间那条从左侧渐变到透明的分隔线去掉了：标题栏和正文之间不再有一道横线，整块工作区看起来是一个整体。
- 工作区里打开的编辑器的四角改用和工作区外壳相同的圆角，不再是之前那圈几乎看不出来的小圆角。

## 修复

- 批量导出卡牌图片时不再提示导出渲染器不可用，卡牌图片可以正常生成。
- 在文件树里对文件夹使用“在文件管理器中显示”时，现在会打开它的父文件夹并选中该文件夹，不会直接进入文件夹内部。
- 文件树里的 `.opencard/icons` 与 `.opencard/packages` 现在使用和其他目录一致的文件夹图标，展开状态也会正常切换图标。
- 文件较多的项目里，打开项目、展开“协作”侧栏或提交新版本时窗口不再卡住几秒。
- “协作”侧栏不再空白：提交过的版本会出现在版本图里，改动过的文件也会出现在“更改”列表里。
- “更改”列表里刚加进项目的包、刚导入的图标包现在显示它们各自的图标与配色——包用包图标，图标包用图标图标——和界面其它位置的同类条目看起来是同一件事，夹在改动里一眼就能认出是新加进来的内容。
- “更改”列表里的未跟踪目录现在显示目录名称和图标，不再出现 `.opencard` 下方只有默认图标的空白条目。
- 名称很长、把整行占满的条目（“更改”列表、文件树里的长文件名），行尾的图标不再被挤到别的行右方、探进滚动条底下：这些行的尾部现在留在原位，由标题那一列自己收起并显示省略号。
- 解开包偶尔失败并提示“拒绝访问”的情况不再出现：系统一时占住刚写入的文件时会自动重试；真的解不开时会在输出面板里说明是哪个文件、为什么，而不是一直停在“正在解开”。
- 侧边栏里的分组标题（例如“模板”“预装的包”）名字很长时不再折成两行把标题栏撑高：现在单行显示，放不下就用省略号截断，鼠标停上去会显示完整标题。
- 在输入框内按 Tab 或 Shift+Tab 不再误触发图层面板，按键会正常在控件之间移动焦点。
- 项目树里已登记的项目字体现在正确显示为已登记状态，不再一律按未登记呈现。
- 实例覆盖了块的原有字段后，属性面板现在也会给出重置操作，与数据表格里的行为一致。
- 某个枚举字段的当前值不在可选项里时（例如值来自另一份文档或更早的数据），字段不再显示空白并把两个箭头一起锁死：现在会显示当前值，并且可以用“下一个”进入选项列表。
- 输入框里的文字不再贴到边框上：以前只有部分输入框自己留了内边距，带尾部按钮的那些（图标页的筛选框、导出对话框的输出目录、属性面板里的枚举步进字段）文字挤在左边、右侧也几乎贴边。现在字段的内缩由字段本身给出，文字落在该在的位置，右侧同样留出内缩。
- 图标页面上的说法和做法对齐了：页面说明不再写“把精灵表切割成图标”（精灵表早已不存在）；矢量图标不再显示没有意义的“像素化”开关，只有位图才有这一项；“配色方式”改成“着色”，两个选项仍是“跟随主题／保留原色”。图标集每一行不再把图标数量印两遍，行上也不再摆着一个点了没反应的按钮。
- 图标页里那条“图标文件无法加载”的提示以前永远不会出现（它依赖的加载错误从来没有被记录过），现在连同它背后的无用代码一并删掉。
- 图标相关的称呼理顺：项目自己的一套图标叫“图标集”，用来导出／导入的那份文件叫“图标集文件”。以前“新建图标集”写成“创建图标包”，对话框里还把图标集的名称与 Key 标成“图标包名称／图标包 Key”，现在两者不再混用。
- 使用英文界面时，界面里剩余的中文文案现在都跟随界面语言显示，包括富文本编辑器的整个工具栏（撤销重做、字体字号、粗斜体下划线删除线、列表、表格、颜色与描边、对齐、清除格式）、卡牌属性面板的富文本窗口与“卡面”“实例”分节标题、实例树与结构树的操作、没有选中对象时的空状态、画布上图片与二维码的失败说明、图片预览编辑器的提示与缩放工具、文档对比读取版本失败时的各类提示，以及系统“选择项目文件夹”“保存文件”对话框的标题与自动保存失败提示。
- 在文档对比视图里从“问题”面板跳到某个块的改动时，之前看起来没有反应：编辑器会去选中当前文档里的块，对比画面却停在原处。现在会直接在对比结果里选中对应块，并把改动前后的值一起展开出来；对比结果里没有的目标按未找到处理，不会再去改当前文档的选择。
- 在文档对比视图里选中实例时，当前文档的选中实例会被一起改写，切回编辑视图后选中的实例已经变了；对比视图里的选择现在只留在对比结果里，不再影响文档本身的选择。
- 在文档对比视图里选中只存在于某一个版本的实例（新增或删除的实例）时，实例树里的选中高亮会立刻消失，而对比画面仍然停在这个实例上；现在高亮会一直保留。
- 在文档对比视图里点击画面上的块没有反应；现在可以直接点击对比画面中的块查看它的改动，右侧属性面板会随之显示改动前后的值。
- 展开版本图里的提交、查看它改了哪些文件之后，版本库一刷新（例如刚提交了新版本、或项目文件发生变化），这些提交就会立刻收起来，得重新展开一遍；现在刷新会保持展开状态，只有确实已经不存在的提交才会收起。
- 工作区标题栏里的版本标识文字，以及设置页滑块里的数值，之前固定在等宽字体上，改界面字体时它们不会跟着变；现在这两处与其它界面文字使用同一套字体。
- 富文本编辑窗口已经打开时切换界面语言，字体与描边宽度下拉、段落对齐按钮和窗口底部的“富文本／HTML 源码”切换不再停留在切换前的语言，现在会立即跟着界面语言更新，不必关掉窗口重新打开。
- 资源管理器里的 `.ocpack` 文件现在显示资源包专用图标：以前用 MSI 安装时它只是一个空白的通用文件图标，用 NSIS 安装时则和 `.ocdocument` 等文件一样只显示应用图标。现在安装时会写上这个图标，应用启动时也会检查一次并按需补写（不需要管理员权限），写完会通知资源管理器刷新。
- 名字被省略号截断的地方，鼠标停上去现在都会显示完整内容：相册卡片的名称与下方的坐标小字、文件树与包列表行尾的小字、编辑器标签页标题、属性名与属性值、下拉框里选中或待选的长名字、菜单项与按钮上的长名字都算在内；以前只有其中少数几处会显示，其余地方一旦截断就再也看不到全名。
- 按住 Tab 看层级视图时，按 S、X、B 现在和其它字母一样按名称或拼音首字母在层级之间遍历，不再切换对齐吸附、卡面边缘裁切与卡面正反面——以前这三个字母仍被画布快捷键接走，和层级视图的按键说明对不上。
- 有几处箭头返回按钮的文案与实际去处不符：从欢迎页进入设置或“关于 OpenCard”后，按钮写着“返回工作区”却回到欢迎页；文档对比视图里的返回箭头写着“返回工作区”，实际只是退出对比回到编辑。现在前两处只说“返回”，对比视图那处改成“退出对比”。
- 重命名文件或文件夹时，如果名字跟原来一样（输入框里没改就确认），不再弹出“无法重命名这个文件或文件夹。”：没有改动就没有可失败的事，现在什么都不做。
- 二级菜单里的命令有时按下没有反应：先在上一级点了“移到回收站”这类会展开子菜单的项（点了没动作，但焦点留在了那一行），再去点它弹出来的“将 xx 移到回收站”时，子菜单会在你按下的那一刻消失，命令自然没跑。现在只要指针或焦点还在子菜单里，子菜单就会一直留着。
