## 新增

- 首次打开自动显示欢迎消息，可选择了解功能导航、侧边栏、主内容区、顶部菜单、任务进度、即时消息和底部面板，可点击左上角的侧栏开关试用收起和展开，最后聚焦“新建项目”，可以直接开始创建；介绍时仅指定区域可操作。首次进入新建项目页会自动引导选择模板、按需选包、填写信息并创建第一个项目；侧栏的“预装的包”更名为“包”，包条目的选择与已选中按钮保持可见，教程提示可点击条目右侧的“预装到新项目”，无需额外点击引导按钮，操作期间仅当前高亮区域及其菜单、教程按钮可交互，其余区域不再响应点击、悬停、提示或光标变化。教程简要说明模板自带的项目内容与包提供的字体、图标、自定义块等资源，关键功能与界面名称统一以代码样式突出显示，操作配上对应图标，选择、点击与悬停配上鼠标图标，填写配上键盘图标，行内图标与文字居中对齐，任务进度和即时消息可在介绍时悬停查看更多，通过遮罩、高亮和曲线说明对应位置；教程名称以小号弱化显示，突出当前步骤标题，右上角以细进度条展示进度，步数在条中央水平、垂直居中显示，并以文字阴影保持清晰。步骤切换时平滑移动和调整大小，可随时结束。在设置中可通过“看过的教程”标签管理记录，移除标签并保存后可再次触发对应引导。

- 图片块可使用图片或项目、资源包中的图标作为透明度遮罩，并可独立设置遮罩的适应方式；透明区域隐藏，清空来源即可取消。
- OcTree 中未指定图标的条目现在显示圆形图标。
- 自定义块现在按集合管理，支持将 `.ocblock` 文件登记到项目资源目录，并使用 `block:集合/块` 引用。
- 自定义块管理页支持从多个文件或文件夹创建集合，批量追加、配置和清理资源，修改后自动保存；预览支持区域裁剪、中键拖动和滚轮缩放。

## 改进

- 下拉框选中勾、资源选择图标和字体文件图标不再使用固定蓝色，统一跟随文字颜色。

- 新建项目以淡化的模糊封面铺满背景并同步轮播，左侧封面保留原有清晰度，右侧表单直接呈现在背景上，字段分组留白更清晰，统一输入控件与详情文字样式；移除模板标题前的图标及表单分隔线；预装的包以标签展示，空状态与单行标签高度一致，长包名省略显示，悬停可查看完整名称。

- 新建项目侧栏中的模板分组和模板条目统一使用压缩包轮廓图标，和包分组、卡牌文档区分开；导入模板的入口从“我的模板”分组移到模板列表标题右侧，和导入包的位置一致。

- 新建项目时，无法使用的模板和包仍保留在列表中，以红色名称标示；悬停可查看原因，用户导入的无效条目可直接删除。

- 教程进度与缓存用量进度条使用更清晰的主题色填充，方便辨认当前进度。
- 用户设置与长期使用记录分开保存；最近项目和项目界面布局独立记忆，重置设置和清理缓存不会清除这些记录。
- 配置文件按深浅主题集中保存颜色、字体与预设，手动查看和调整主题更直观。

- 协作独立为一级空间，与工作台共享当前编辑器、文件会话和差异查看；侧栏不再通过顶部标签切换内容组。
- 未打开项目时，协作空间会显示打开项目入口和明确的空状态提示。
- 卡片编辑器的卡片树、预览、结构树与属性面板不再单独折叠，内容保持展开。
- 侧栏宽度、侧栏列表高度与下方面板高度支持方向键调整；拖动中按 Esc 可取消调整。
- 侧栏与页面使用统一的滚动条外观，关于页与更新弹窗中的更新说明采用一致的排版。
- 文件夹图标统一使用黄色，更容易与文件区分。
- 空间栏图标统一改用实心样式，导出空间改用打印机图标。
- 文件树每层都将文件夹排在文件前，两组分别按名称排序。

- 文件树支持 Ctrl 多选和 Shift 范围选择，可通过右键菜单批量复制路径或移到回收站；删除前统一确认未保存内容。

- 图标着色改为“跟随上下文”，使用所在位置的文字颜色；移除图标旋转设置及专用图标集文件的导入、导出，图标分享统一使用资源包。
- 欢迎页和没有项目、文件的空工作台不再显示内容页头，留出更多内容空间。
- 富文本编辑器顶部的字体、字号和描边宽度支持直接输入，并可从建议列表中快速选择；按 Enter 确认时优先保留精确匹配的输入值。
- 富文本编辑器的工具栏与右侧属性区同步选区格式；修改格式保留文字、图标和表格选区，颜色预览取消不影响正文及撤销记录。
- 富文本编辑窗口加宽，属性区独立放在窗口外部右侧，支持拖动调宽、拉回收起及从右边缘展开；双击分隔条可收起或恢复上次宽度，也可聚焦后按 Enter 切换，主编辑区宽度保持不变。
- 弹窗底部操作区的四边留白统一，按钮与边缘的距离更一致。
- 富文本与 HTML 源码切换保留撤销记录，未修改内容保存时保留原文；图片填充、项目字体和资源包图标在切换后继续保留。
- 富文本中的 binding 双击后直接进入行内编辑，减少重复的编辑弹窗。
- 富文本 binding 编辑时按表达式内容自动调整宽度，不再显示多余的选中框和背景高光，补全项的名称与路径恢复为横向排列。

- 切换页面后返回新建项目或模板导出，保留尚未提交的表单与选择；重新开始流程时清空草稿。
- 放弃版本修改前统一确认受影响文件的未保存内容；取消或保存失败时停止操作。

## 修复

- 删除等确认弹窗与未保存文件提示的正文恢复在内容区显示，不再挤在标题下方留下空白内容区；移除包的确认文案精简为“是否移除”。

- 富文本编辑窗口恢复正常加载，可继续编辑和保存文本。
- 使用资源包字体或比较历史版本时，字体与图标按各自来源显示，不再串用当前项目的资源。

- 图片目录删除后，路径补全不再报错；图片变化时只刷新相关资源，删除目录后预览不再继续显示旧图片。

- 项目外的图片可独立预览，不再错误地从当前项目目录查找图片。
- 带子菜单的图标按钮恢复悬停时的名称提示。
- Markdown 块和文本框块的内容补全重新包含资源包中的图标。
- 清空图片遮罩来源后，原图会正常恢复显示；遮罩来源不会再被误报为必填。
- 图片来源和遮罩来源都恢复项目与资源包图标的自动补全。
- 属性编辑器的自动补全菜单在离开输入框后会正确关闭。
- 原始字符串编辑器改为由 PropertyEditor 显式开启，字段也可以单独覆盖这一设置。
- 调整底部面板高度时，预览线与百分比提示不再被卡片编辑器遮挡。
- 弹窗中的菜单与下拉面板随所属弹窗显示，背景页面浮层和文件拖放提示不再覆盖当前弹窗。
- 返回卡片编辑器后，恢复此前的画布缩放与位置。
- 保存文本文件时继续编辑，后续修改仍会显示为未保存。
- 导入或导出工作簿时，文件选择窗口打开期间不再重复启动同一操作。
- 导出卡片图片时，文件写入失败会显示错误提示。
