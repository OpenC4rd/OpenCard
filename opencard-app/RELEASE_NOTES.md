# 发行说明草稿

## 新增

- 资源包改用「作者/包名@版本」这套坐标来标识，并且坐标由**包自己**在清单里说清楚：把 `.ocpack` 文件放进项目的 `.opencard/packages/` 就算装好了，项目里有哪些包就是文件夹里有哪几个包，不再需要另外维护一份包清单，也不再需要 `.gitignore`。文件叫什么名字、放在哪里都不改变它是谁，所以别人给你的项目、或者你自己改过名的包，打开之后还是同一个包。卡片与包之间引用包内资源用的也是这套坐标，写不写版本由你定：写了就把长相钉死，不写就用装着的里面最新的那一版。
- 侧栏 `.opencard/packages` 这一行现在可以点开一个“包”页面：它就是这个包文件夹的相册版——有几份归档文件就有几张卡，卡片的标题是文件名，下面一行小字是包自己声明的坐标，和侧栏里那一行字字相同。卡片上画着包的封面（封面取自已解压的包内资源，和卡片引用包内图片走同一条路，还没解开的包媒体区留空）。说不清自己是谁的归档不会被悄悄藏起来，而是单独列出来并说明读不出来的原因。每张卡片上有“在文件管理器里显示”和“移除包”——移除会先问一次，确认后把那个归档移到回收站，想反悔从回收站拿回来再放回去就行。相册是文件夹的可视化：内容完全相同的两份也各占一张、按文件名排列（标题就是各自的文件名，不会看着一模一样），而引用仍按内容取先出现的那个文件名；同一个包换成新构建（坐标相同、内容不同）时两份也都列出来。点卡片直接打开这个包的详情，详情里的封面、内容特征码与清单都直接读自这个归档——没解开也看得见，重复的那一份看的也是自己那份。
- 打开的包不再解到项目里，而是解到软件存储的缓存中、按内容特征码命名，所有项目共用：同一个包在多少个项目里用到都只解一次，缓存也可以随手删掉，下次用到会重新解一遍（缓存有大小上限；一边用不会一边清，超出上限的部分留在下次启动时从最久没用到的开始清）。打开项目时，还没解开的包在后台排队解压，不挡住打开项目；某个包在这台机器上第一次被用到时会空一拍，随后自己补齐。
- 往项目里加包和以前一样简单：把一个 `.ocpack` 文件拖进已打开的项目，或在侧栏 `.opencard/packages` 这一行点“添加包”选一个文件，它就被复制进项目；在“新建项目”页勾选的包也会一起复制进去。归档按原样复制、名字不变，和复制别的文件走同一条路：撞名时排下一个编号（`名字 (2).ocpack`），不覆盖已有的那一份。侧栏的包列表里，每一行的标题就是文件本来的名字，下面一行小字是包自己声明的坐标，一眼看得出这个文件是谁；包行上的操作和文件树里的文件完全一样——重命名、移到回收站、在文件管理器里显示、复制相对路径与绝对路径，整棵结构树也接受把 `.ocpack` 从外面拖进来。每个包自带作者、包名、版本与显示名，打开包清单就能看到它是谁、内容特征码是什么；哪怕这个文件不在项目的包列表里（比如同一份内容被放了两个文件名），预览也照样照实显示它是什么。
- 图片块的图片来源除了填写文件路径，现在可以直接挑选项目图标或包内图标：在来源里输入 `icon:` 会列出当前项目的图标集合，以及随包提供图标的包；选中某个包后候选里会继续出现 `icon:`，一路选下去就能写入该包图标的引用，直接在来源里输入 `作者/包名@版本#` 也能接着补全。候选列表只显示名称，选中集合后再挑图标即可。
- 富文本的图标菜单现在按来源分组，当前项目与每个包各自的图标集合分开列出；插入的图标会记住它来自哪个包，只读预览与卡片渲染都会照常显示包内图标。
- 外观设置的主题预设里新增“石墨”：它沿用所属主题的底色与文字颜色，只把主题色换成纯黑或者纯白（深色主题用纯白，浅色主题用纯黑），深色与浅色两套主题的预设列表中都可以直接选用。
- 外观设置新增“窗口云母背景”开关。开启后窗口底层交给 Windows 11 的云母材质，标题栏与面板之间的空隙会透出桌面壁纸的质感，并跟随深色／浅色主题取用对应的明暗；系统不支持时会给出提示，界面保持原来的不透明底色。
- 添加项目字体时除了从文件导入，现在还能直接导入电脑上已安装的系统字体：在添加字体对话框顶部切到“从系统字体导入”，按名称搜索或在树里展开字系核对识别到的字面，勾选一个或多个系统字系后确认，OpenCard 会把每个字系的字重与斜体各自整理成一套项目字体并复制进项目，一次就能导入多套；勾选过的字系可以用“只看已选中”过滤出来，列表里的字系名会用该字系自己的字体显示，装了多少、长什么样都能直接看到。
- 设置里新增“协作”分类：作者身份（作者 ID）搬到了这里，并新增提交者名称、提交者邮箱，以及初始化仓库后是否自动创建首次提交。提交者名称留空就用作者 ID，邮箱留空再按提交者名称自动生成 `@noreply.example` 地址，一次填好之后每个项目都用这套身份。
- “更改”列表里每条改动后面都有一个勾选框，默认全部勾选；点“提交版本”只暂存并提交勾选的条目，没勾的改动原样留在工作区，按钮上会显示这次会带上多少条。
- “更改”列表里每条改动可以右键：**放弃更改**（提交过的内容恢复到最近一次提交，新增的文件移到回收站，动手前会确认）、**忽略此文件**、**忽略此文件夹**（子菜单列出从它自身到项目根的每一级目录）、**忽略所有这类文件**（例如所有 `.ocpack`）。忽略规则写进项目的 `.gitignore`，被忽略的未跟踪内容随即从“更改”里消失；已经提交过的文件不受忽略影响，仍会留在列表中。
- 设置的“通用”里新增“缓存”卡片：解开的包、从网上下载过的图片、撤销暂存各占多少一眼可见（写成「已用 / 上限」），解开的包与下载的图片还各有自己的上限可以调（默认 2 GB 与 1 GB），需要时点“清理缓存”把这一块整个清掉。清理不会丢东西——包的本体留在项目里，下次打开项目会重新解开，下载过的图片下次用到时重新下载；超出上限的部分在下次启动时才收，一边用不会一边清，项目打开着的时候也不提供清理，免得把正在用的东西删掉。
- “新建项目”页的内置模板里新增“换皮扑克牌”：一张标准尺寸的扑克牌蓝图，纸张、墨色、强调色、点数、花色与系列标识都在属性面板的“自定义字段”里直接改，四个示例实例（黑桃 A、红心 K、梅花 Q、方块 J）各带一套配色，切过去就能看效果。
- 图标集现在可以直接补充图标：在图标集那一行点“添加图标”，选若干文件或一整个文件夹，新的图标会加进这个图标集、和它原有的图标放在同一个文件夹里，不必为了多几个图标重建整个图标集；给图标集改名或改 Key 仍然只在“图标集设置”里做。

## 改进

- 设置页改为平铺分组：每组不再有卡片底色和描边，只保留标题栏与行之间的分隔线，整页直接落在窗口底色上；开启“窗口云母背景”时，设置页会与标题栏一样透出系统材质。
- 设置页每一行的输入区改成统一宽度：颜色、文字、数字、下拉、选项组与滑块都占同一宽度，选项组不再随文字长短伸缩、滑块也不再独占整列。
- 表单里的选项组（设置页的主题，以及属性面板里的同类字段）改用滑动描边样式：与侧栏的工作区切换一致，选中框会滑到新选项上，不再只靠按钮底色区分。
- 滑块圆点改成单色实心圆：去掉 2px 描边和外面那圈细线，小圆的边缘不再发虚，和开关的小圆是同一种做法。
- 滑块的刻度不再画在滑轨最两端（那里只剩圆角），中间的刻度与滑轨齐平，不再从滑轨边界探出去。
- 滑块手柄不再随悬停或拖动改变大小：拖动时数值读数照常出现，但圆点始终保持原尺寸。
- 滑块的圆点与刻度都对齐到设备像素：圆点不再停在半个像素上把边缘糊掉；刻度改成正好一个设备像素宽、并落在同一相位上，不再一根粗一根细。
- 开关在切换时小圆先朝行进方向拉长一点、再滑过去收成正圆；系统要求减少动态效果时不播放这段动画。
- 项目设置的封面改为整幅图片预览：点击封面即可从项目文件夹中挑选图片，图片路径与移除操作收在封面底部的毛玻璃信息条里（相册卡片的同一套布局，悬停时出现移除操作），不再需要手动填写图片路径；包清单页面的封面也统一改用同一套封面呈现。
- 项目图标页重新按“图标本身”排布：左边是图标集列表，中间是当前图标集的图标网格——每张卡片正面画的就是这个图标，悬停时出现复制、移动与移除；右边是选中图标的预览与属性，属性不再占用一块可收起、可拖高的浮动面板。预览现在可以用滚轮缩放、拖动平移，双击或点工具栏上的“适应窗口”回到原来的大小；换一个图标或换一个图标集，缩放也会回到默认大小，不会把上一个图标的缩放带到下一个。选中多个图标时右栏会说明已选了几个、卡片上的操作会同时作用于它们，不再让人以为在编辑其中的某一个。
- 设置页按主题重新分组：每个分类下的设置现在分成一张张卡片（外观下是“深色主题”“浅色主题”“界面”，工作区下是“保存与历史”“文件树”“画布辅助”），卡片自带标题，作用于整组的操作放在卡片上。一条设置只承载一个值，深色与浅色主题不再层层嵌套。
- 主题预设的复制与读取改为一对卡片操作：在一套主题的卡片上“复制这套主题预设”，再在另一套主题或另一台设备上“从剪贴板读取主题预设”，不再需要先弹出窗口粘贴 JSON；删除导入的预设、重新生成作者 ID、重置本项目的界面状态也一并移到了对应卡片上，预设选择器旁边不再挂着按钮。
- 欢迎页背景封面墙每次打开应用都换一个排布与取景：同一张封面在不同格子里露出的部位不再一样，整面墙也不再次次是同一张图案。
- 卡牌编辑器里按住 Shift 拖动选择框的缩放点就是等比缩放：宽高按原比例一起变，松手前就能从选择框上看出结果。跟手的是比较长的那条边（拖边时就是那条边自己），所以整段拖拽只有一个方向在跟指针，不会拖到一半换方向、来回抖。等比缩放时对齐吸附照常生效，而且两条边都能吸：哪条边离对齐线更近就吸哪条（包括不跟手的那条），吸上之后比例仍然保持不变，引导线也只画在真的吸住的那条边上。
- 主题卡片新增“主题名称”一行：给当前这套配色起个名字就会存成一条自定义预设，改名字就是给它改名，配色、字体与次级颜色相位角一起记住；不必再靠复制成 JSON 再读回来才能留下自己的配色。
- 主题预设的选中状态现在记的是“选中的是哪一条”，不再按颜色反推：颜色相同、名字不同的两条预设不会再互相顶替，预设列表里也不再用“已导入”当后缀。导入一套与已有预设完全相同的主题时不再多出一条重复的预设，只会把已有的那条选上；名字撞车但配色不同的导入会自动加序号，不再顶掉前一条。
- 数值滑块不再在滑轨右侧常驻一块数值，而是把当前值显示在拇指上方：鼠标悬停、拖动或键盘聚焦时持续显示，移开鼠标就把整条滑轨的宽度让出来；带单位（`%`、`°`、`px` 等）时单位跟在数值后面。以前只有带单位的滑块才显示数值，现在每个滑块都能看到当前值。
- 下拉选择与自动补全的候选行改用统一条目样式：当前高亮项与已选项现在能区分开（已选项用与树、列表一致的选中底色，此前下拉里只是把文字变色）；自动补全的说明文字从候选右侧的第二列改为标题下方的一行，长短不一时不再互相挤压。
- 反馈历史列表里选中一条记录时，底色改为与属性面板等其它列表一致的选中色，不再是另一种灰底；左侧那条主题色标记线保持不变，选中项在整页里看起来是同一套样式。
- 项目字体与字体组合的添加入口从编辑器标题栏移到左侧列表：鼠标移到“项目字体”或“字体组合”这一行，或在该行右键，就会出现对应的添加入口（“添加字体”“创建字体组合”），标题栏不再常驻两个加号。
- 添加字体对话框顶部改成“从文件导入／从系统字体导入”两种来源的切换，各自显示对应的内容；从文件导入保持原来的做法（选择字体文件后自动识别名称、字重和样式），并且对话框不再一打开就弹出文件选择框。
- 字体管理器左侧列表里，项目字体和字体组合的名字现在用它们自己的字体显示：字体条目用它自己的字面绘制（组合按成员的回退顺序绘制），不必再靠右侧预览区确认某个名字对应的是哪套字体；右侧的悬停预览保持不变。
- 设置页把原来那张“更新与导出”拆成“更新”和“导出”两张卡片，各自只放自己的设置：更新一侧的开关改成“展示版本说明”（打开即更新后自动弹出版本说明，默认打开），导出一侧是“导出后自动打开”。
- 更改列表里每条只显示文件名，不再显示整条相对路径；同一层里出现同名文件时，只给重名的那几条补上能区分的目录（例如 `icons/logo.svg` 与 `photos/logo.svg`），其余仍只有文件名。位于 `.opencard`、`.git` 这类点开头目录中的文件各自收进一个同名子节点（默认展开，可以收起），普通文件直接列在根上；版本图里每次提交的文件清单也按同样规则显示。
- 项目配置新增“项目作者”字段；制作资源包时的作者默认填入它，不再和设置里的作者 ID 联动——原先制作页会把你填的作者写回设置，现在两边各管各的，包作者只在项目内记住。
- 制作资源包改由后端直接读盘打包：不再把每个文件读进界面再压缩，制作时进度条会随文件推进而不是一直停在起点，也已压缩的图片与字体不再重复压缩，大包的制作时间与占用明显下降。
- 包摘要会列出包里各式内容的数量（字体、字体组合、图标、图片），并且给包身份留出四个输入框：作者、包名、版本，以及给人看的显示名（留空就用包名）。不再单独显示一行只读的“包 Key”——一个包是谁，由这四项自己说清楚。
- 打包资源包时把用到的资源**复制进包里**：来自别的包的字体与图标会以它们在来源包里的相对路径放进新包，包内注册表改指这些包内路径，所以新包里不再有任何对别的包的引用，也不需要一份依赖清单。项目自己的资源照旧按它们在项目里的位置进包。
- 设置页每条设置现在可以带一行说明文字：标题只留短名字（例如“即时信息”“自动保存”“历史记录上限”“结构树选中”“滚动定位”“定位辅助线”“宽高标签”“自动吸附”“首次提交”“导出后自动打开”），原本塞在标题里的解释挪到标题下方的小字里显示。
- 启动封面、关于页与 .ocpack 文件类型图标里的 OpenCard 标志改用矢量图形：放大到任意尺寸、在高分辨率屏幕上边缘都不再发虚，重新生成文件类型图标时也不再依赖外部的标志位图。
- 初始化仓库不再弹出询问身份的对话框：直接使用设置里“协作”分类的提交者身份，并按其中的选项决定要不要顺手创建首次提交；名称与邮箱都能从作者身份兜底，所以不再打断操作，只有 Git 不接受这套身份时才会把你带到对应的设置项。
- “新建项目”页的模板与包都改成两个分组：模板下是“内置模板”和“我的模板”，包下是“内置的包”和“我的包”（内置包来自随安装包一起发布的包）；两组默认展开，可以随时收起，不再是把内置项直接铺在根上。
- 删除用户模板不用再先选中它、再回到右侧详情里点按钮：把鼠标移到“我的模板”里的模板那一行，直接点行尾的删除图标即可，确认后移除。内置模板不提供这个入口。
- 移除包、删除模板时的确认改成了应用内对话框，和其余弹窗同一套外观，不再弹出操作系统的消息框。
- “预装的包”列表支持多选，列表头部在“导入包”旁边新增“使用选中的包”和“禁用选中的包”，可以一次把选中的包全部预装或全部取消；树里的每次单项切换仍然保留。包相关的措辞统一为“包”，“附加包”不再出现。
- “打开的编辑器”列表与页面顶端的标题、图标现在始终是同一份：显示编辑器自己给出的名称与图标，不再出现列表一个名字、顶端另一个名字；受管文件也跟着这样显示（项目配置显示“配置”，包显示文件自己的名字与它声明的坐标，不再是统一的“包”）。双击文件不会再把这个名称变回文件名，编辑器给出名称之前两处保持空白，不会先显示文件名再改。
- “打开的编辑器”列表里的字体文件图标与文件树保持一致：没有登记到项目字体的字体文件按未登记呈现，不再出现同一文件在文件树里变暗、在列表里却是彩色。
- 卡牌编辑器里新建的块一出场就带上自己的尺寸和该有的样式：每个新块都有宽高，文本块与 Markdown 文本块还带上字号、字重、字体颜色、对齐方式与行高，不必先去属性面板逐项“添加”。以前文本块没有字号，卡片上的文字会跟着软件界面的字号一起变；现在卡片自己说了算。旋转、不透明度、描边、圆角、自定义 CSS 这些仍然保持未添加，需要时再从属性面板加上。

## 修复

- 文件较多的项目里，打开项目、展开“协作”侧栏或提交新版本时窗口不再卡住几秒；版本库相关的查询现在不再占住界面。
- “协作”侧栏不再空白：提交过的版本会出现在版本图里，改动过的文件也会出现在“更改”列表里，不再出现明明改过文件、明明提交过版本却什么都看不到的情况。
- “更改”列表里刚加进项目的包、刚导入的图标包现在显示它们各自的图标与配色——包用包图标，图标包用图标图标——和界面其它位置的同类条目看起来是同一件事；以前它们只是通用的文件图标，夹在改动里不容易认出是新加进来的内容。
- 名称很长、把整行占满的条目（“更改”列表、文件树里的长文件名），行尾的图标不再被挤到别的行右方、探进滚动条底下：这些行的尾部现在留在原位，由标题那一列自己收起并显示省略号。
- 解开包偶尔失败并提示“拒绝访问”的情况不再出现：系统一时占住刚写入的文件时会自动重试；真的解不开时会在输出面板里说明是哪个文件、为什么，而不是一直停在“正在解开”。
- 侧边栏里的分组标题（例如“模板”“预装的包”）名字很长时不再折成两行把标题栏撑高：现在单行显示，放不下就用省略号截断，鼠标停上去会显示完整标题。
- 在输入框内按 Tab 或 Shift+Tab 不再误触发图层面板，按键会正常在控件之间移动焦点。
- 项目树里已登记的项目字体现在正确显示为已登记状态，不再一律按未登记呈现。
- 实例覆盖了块的原有字段后，属性面板现在也会给出重置操作，与数据表格里的行为一致。
- 某个枚举字段的当前值不在可选项里时（例如值来自另一份文档或更早的数据），字段不再显示空白并把两个箭头一起锁死：现在会显示当前值，并且可以用“下一个”进入选项列表。
- 输入框里的文字不再贴到边框上：以前只有部分输入框自己留了内边距，带尾部按钮的那些（图标页的筛选框、导出对话框的输出目录、属性面板里的枚举步进字段）文字挤在左边、右侧也几乎贴边。现在字段的内缩由字段本身给出，文字落在该在的位置，右侧同样留出内缩。
- 图标页面上的说法和做法对齐了：页面说明不再写“把精灵表切割成图标”（精灵表早已不存在）；矢量图标不再显示没有意义的“像素化”开关，只有位图才有这一项；“配色方式”改成“着色”，两个选项仍是“跟随主题／保留原色”。图标集每一行不再把图标数量印两遍，行上也不再摆着一个点了没反应的按钮。
- 图标页里那条“图标文件无法加载”的提示以前永远不会出现（它依赖的加载错误从来没有被记录过），现在连同它背后的无用代码一并删掉。
- 图标相关的称呼理顺：项目自己的一套图标叫“图标集”，用来导出／导入的那份文件叫“图标集文件”。以前“新建图标集”写成“创建图标包”，对话框里还把图标集的名称与 Key 标成“图标包名称／图标包 Key”，现在两者不再混用。
- 使用英文界面时，界面里剩余的中文文案现在都跟随界面语言显示，包括富文本编辑器的整个工具栏（撤销重做、字体字号、粗斜体下划线删除线、列表、表格、颜色与描边、对齐、清除格式）、卡牌属性面板的富文本窗口与“卡面”“实例”分节标题、实例树与结构树的操作、没有选中对象时的空状态、画布上图片与二维码的失败说明、图片预览编辑器的提示与缩放工具、文档对比读取版本失败时的各类提示，以及系统“选择项目文件夹”“保存文件”对话框的标题与自动保存失败提示。
- 在文档对比视图里从“问题”面板跳到某个块的改动时，之前看起来没有反应：编辑器会去选中当前文档里的块，对比画面却停在原处。现在会直接在对比结果里选中对应块，并把改动前后的值一起展开出来；对比结果里没有的目标按未找到处理，不会再去改当前文档的选择。
- 在文档对比视图里选中实例时，当前文档的选中实例会被一起改写，切回编辑视图后选中的实例已经变了；对比视图里的选择现在只留在对比结果里，不再影响文档本身的选择。
- 在文档对比视图里选中只存在于某一个版本的实例（新增或删除的实例）时，实例树里的选中高亮会立刻消失，而对比画面仍然停在这个实例上；现在高亮会一直保留。
- 在文档对比视图里点击画面上的块没有反应；现在可以直接点击对比画面中的块查看它的改动，右侧属性面板会随之显示改动前后的值。
- 展开版本图里的提交、查看它改了哪些文件之后，版本库一刷新（例如刚提交了新版本、或项目文件发生变化），这些提交就会立刻收起来，得重新展开一遍；现在刷新会保持展开状态，只有确实已经不存在的提交才会收起。
- 工作区标题栏里的版本标识文字，以及设置页滑块里的数值，之前固定在等宽字体上，改界面字体时它们不会跟着变；现在这两处与其它界面文字使用同一套字体。
- 富文本编辑窗口已经打开时切换界面语言，字体与描边宽度下拉、段落对齐按钮和窗口底部的“富文本／HTML 源码”切换不再停留在切换前的语言，现在会立即跟着界面语言更新，不必关掉窗口重新打开。
- 资源管理器里的 `.ocpack` 文件现在显示资源包专用图标：以前用 MSI 安装时它只是一个空白的通用文件图标，用 NSIS 安装时则和 `.ocdocument` 等文件一样只显示应用图标。现在安装时会写上这个图标，应用启动时也会检查一次并按需补写（不需要管理员权限），写完会通知资源管理器刷新。
- 名字被省略号截断的地方，鼠标停上去现在都会显示完整内容：相册卡片的名称与下方的坐标小字、文件树与包列表行尾的小字、编辑器标签页标题、属性名与属性值、下拉框里选中或待选的长名字、菜单项与按钮上的长名字都算在内；以前只有其中少数几处会显示，其余地方一旦截断就再也看不到全名。
- 有几处箭头返回按钮的文案与实际去处不符：从欢迎页进入设置或“关于 OpenCard”后，按钮写着“返回工作区”却回到欢迎页；文档对比视图里的返回箭头写着“返回工作区”，实际只是退出对比回到编辑。现在前两处只说“返回”，与“新建项目”“导出模板”页的返回按钮是同一个，对比视图那处改成“退出对比”。
